# Demo Taqui

Recorrido automático de **Taqui by VertexSur** (venta de entradas): portada comercial y demo guiada de comprador, productora y elenco, con datos de ejemplo.

- Un solo archivo: `index.html` (imágenes y estilos adentro).
- Se publica con GitHub Pages desde `main`.
- Cambios: se suben a la rama `DEV` y pasan a `main` por pull request.
